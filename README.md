# OpenCode Murmure Voice

Projet de plugin **OpenCode V2** indépendant, connecté à [Murmure](https://github.com/Rwanbt/murmure) pour la reconnaissance (STT) et la synthèse vocale (TTS) **locales**.

**Périmètre :** transcription de prompts avec aperçu et validation, lecture des réponses OpenCode, contrôles pause/reprise/stop et petite capsule hover via une fenêtre indépendante sous Windows, sans modification du code officiel d’OpenCode.

**Hors périmètre :** Jarvis, mot de réveil, écoute permanente, conversation full-duplex, acceptation vocale automatique de permissions.

**État :** planification uniquement. Pas encore de plugin opérationnel ni de tests exécutés.

Les travaux suivent les issues GitHub et des Draft PR vérifiées au SHA exact.
