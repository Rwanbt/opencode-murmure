# Roadmap OpenCode V2 — STT/TTS uniquement

- **O0 Fondation** : contrat plugin V2, build TypeScript et CI, matrice versions OpenCode.
- **O1 Liaison Murmure** : découverte du service local authentifié, négociation de version, comportement sans Murmure.
- **O2 STT** : session explicitement sélectionnée, transcription modifiable avant envoi, annulation et gestion focus.
- **O3 TTS** : événements réponses OpenCode, segmentation, lecture Pocket TTS filtrée, stop/pause/reprise, reconnexion sans doublons.
- **O4 Overlay** : capsule hover flottante externe au Desktop, contrôles et a11y ; fallback TUI sans UI native.
- **O5 Qualification** : E2E Desktop packagé Windows, tests TUI, sécurité/permissions, absence de patch d'OpenCode, compatibilité upgrades.

Précondition O2/O3 : API locale Murmure stable et sécurisée. Les détails sont tracés par les issues OC-001…OC-012. **Pas de Jarvis ou conversation continue dans cette phase.**
